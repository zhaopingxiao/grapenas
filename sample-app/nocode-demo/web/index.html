葡萄云示例应用

免访问码页面

这个页面由示例应用自己的 HTTP 服务提供，葡萄云把它的 nocodeport 代理到了 /nocode/nocode-demo/ —— 这一段路径不校验访问码，换台设备直接打开就能看。

不要访问码

/nocode/nocode-demo/

当前页面就是从这里打开的（浏览器地址栏可对照）。

要访问码

/nocode-demo/

同一个应用的 port 入口，未登录会被葡萄云挡回访问码页。

未调用 
点上面的按钮，请求会发到相对路径 api/info

页面里的 style.css、app.js、api/info 都是相对路径， 所以同一个页面在两个入口下都能正常工作。
