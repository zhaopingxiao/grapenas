# Web Desktop (Node.js)

用浏览器远程查看并控制本机桌面的 Node.js 项目：服务端持续截屏并以 JPEG 流推送，浏览器端显示画面并把鼠标、滚轮、键盘事件回传给服务端注入系统。

## 技术栈

| 功能 | 实现 |
| --- | --- |
| 截屏 | [node-screenshots](https://www.npmjs.com/package/node-screenshots)（Rust/xcap，N-API 预编译，支持多显示器、Hi-DPI 物理像素） |
| 缩放 / JPEG 编码 | [sharp](https://www.npmjs.com/package/sharp)（libvips 预编译） |
| 鼠标 / 键盘注入 | [koffi](https://www.npmjs.com/package/koffi) 调用 Win32 `SendInput` / `SetCursorPos`（FFI，无需编译，支持虚拟键码和扩展键） |
| 服务端 | express + ws（WebSocket） |

全部依赖均为预编译二进制，`npm install` 不需要 Visual Studio 编译环境。

## 功能

- 实时画面串流（自适应背压，客户端跟不上时自动降帧，不堆积延迟）
- 鼠标移动 / 左中右键 / 侧键 / 双击 / 滚轮（含横向）
- 完整键盘控制（物理键位 → Windows 虚拟键码，支持 Shift/Ctrl/Alt/Win 组合键，方向键等扩展键正确标记）
- 多显示器选择、画质 / 帧率 / 缩放实时调节
- 手机触屏：单指拖动 = 鼠标拖动，长按 = 右键，双指上下滑 = 滚轮，双指轻点 = 右键
- 访问令牌鉴权，令牌随服务启动随机生成
- 启动时自动设置进程 DPI 感知，150% 缩放等 Hi-DPI 环境下坐标依旧精确

## 安装

需要 Node.js 18+（推荐 20+）。

```powershell
cd D:\code\webpg
npm install
```

或直接双击 `start.bat`（首次运行自动安装依赖并启动）。

## 使用

```powershell
node server.js
```

启动后终端会打印带令牌的访问地址：

```
本机:   http://127.0.0.1:8000/?token=xxxxxx
局域网: http://192.168.0.101:8000/?token=xxxxxx
```

- 本机浏览器直接打开即可。
- 手机 / 其他电脑连同一局域网，打开「局域网」地址即可。
- 首次访问 Windows 防火墙弹窗时选择「允许」。

### 常用参数

| 参数 | 说明 | 默认 |
| --- | --- | --- |
| `--host` | 监听地址 | `0.0.0.0` |
| `--port` | 端口 | `8000` |
| `--token` | 固定访问令牌 | 每次随机 |
| `--monitor` | 初始显示器序号 | `0` |
| `--quality` | JPEG 画质 10-95 | `70` |
| `--fps` | 目标帧率 1-60 | `30` |
| `--scale` | 串流缩放 0.2-1.0 | `1.0` |

示例：`node server.js --port 9000 --token mysecret --fps 20 --scale 0.75`

## 操作说明

- 点击画面后键盘才会生效；画面失焦会自动释放所有按键，避免按键卡死。
- 页面右上角可实时调整画质、帧率和缩放；卡顿时优先降画质或缩放。
- 顶部「适应窗口 / 原始大小」切换显示方式，「全屏」按钮进入浏览器全屏。
- 若令牌填错，会提示重新输入；连接中断会自动重连。

## 安全提醒

- 本工具等同于把电脑的鼠标键盘交给能访问该地址的人，**只建议在可信局域网内使用**。
- 不要用路由器端口映射等方式暴露到公网；确需公网使用请套 HTTPS 反向代理并设置强令牌。
- 令牌是唯一凭证，泄漏后请重启服务更换（或使用 `--token` 固定一个强口令）。

## 已知限制

- `Ctrl+Alt+Delete` 无法模拟（Windows 安全机制），请在目标机上直接操作。
- 浏览器的 `Ctrl+W`、`Ctrl+T`、`Ctrl+N` 等少数快捷键会被浏览器自己拦截，无法发送到远端。
- 按 Win 键会打开本机开始菜单（操作系统层拦截），建议用鼠标点开始菜单。
- 目标机未以管理员身份运行时，无法控制以管理员权限运行的窗口（UAC 隔离），建议右键「以管理员身份运行」启动服务。
- 锁屏界面、UAC 弹窗无法通过该方式操作。
- 画面中不包含鼠标指针，指针由本地浏览器显示。
